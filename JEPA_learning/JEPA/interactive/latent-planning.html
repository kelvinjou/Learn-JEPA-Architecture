Planning in latent space

V-JEPA 2's planner, in miniature. A frozen encoder, an action-conditioned predictor learned from random play, and the Cross-Entropy Method searching for the action sequence whose imagined final embedding lands closest to the goal embedding. No reward function, no value function, no policy network.

Click an empty cell to move the goal. Shift-click to move the agent. Alt-click to toggle a wall.

The whole method E(â1:T) = ‖ P(â1:T; zk) − zg ‖1,   a* = argminâ E(â1:T)
Encode the goal image once. Roll candidate action sequences through the predictor in embedding space. Score by ℓ₁ distance to the goal embedding. Execute only the first action, observe, re-plan. That is receding-horizon control, and it is exactly Eq. 5 of the V-JEPA 2 paper.
Three things to try 1. Break greedy planning. Set the horizon to 1. The default layout has a barrier the agent must go around, so every single-step move that reduces the goal distance is blocked and the agent oscillates in front of the wall forever. At T = 6 it solves the same layout in under 20 steps. That gap is exactly why V-JEPA 2 needs intermediate sub-goal images for pick-and-place: their planning horizon is 1.
2. Watch error accumulate. Raise the predictor noise and watch plot (a). The one-step error barely moves while the 6-step error roughly triples — errors compound through the rollout, not along it. Short horizons stay usable; long ones stop meaning anything. The paper names this failure: "the accuracy of the representation-space predictions decreases with longer autoregressive rollouts."
3. Compare the honest baseline. Turn on "plan with true dynamics". The planner now uses the simulator instead of the learned predictor. Any gap between the two is entirely the predictor's fault, and separating those two error sources is most of what debugging a world model consists of.
Trap The planner never sees the grid. It sees an 8-dimensional embedding produced by a frozen random encoder and a random-feature ridge regression per action, learned from random play. When the agent walks into a wall, the encoder returns the same embedding it had before — so as far as the predictor is concerned, nothing happened. Watch the imagined path (dashed) diverge from the executed path (solid) whenever a wall is involved.
